An entry for the make.fun bounty **One-Star Review of Something Essential**: the funniest deadpan one-star review, in a single line of at most 160 characters, of an everyday essential nobody can opt out of.

This entry files its complaint against gravity. It works every time, it has no off switch, and it has personally dropped the reviewer's phone, coffee and dignity. The review is delivered completely straight — one star, no exclamation marks, no appeal — and saves its sting for the last few words: the reviewer would fall again, because there is no choice.

## How it runs

`main.ts` is a dependency-free Node program (program/v1 harness). When run, it clears the contents of the output directory (the directory itself is a mount point and is never removed), then writes the review to `entry.txt` with no trailing newline — 128 characters of UTF-8 text, inside the contest gate.
